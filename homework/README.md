פרומפטים לדוגמא עם סיכום מהשיעורי בית:
1. הגדרת שכבת הנתונים (Data Layer)
הקשר בקוד: יצרנו פונקציות בסיסיות (CRUD) לניהול המערכים בזיכרון בתיקיית data/ (studentsData.js ו-coursesData.js).

פרומפטים/שאלות שעלו:

"אני צריכה קודם להעביר את כל הפרויקט שהיה לי מקודם עכשיו להעביר אותו לתיקיות. אז אני קודם רוצה להעביר את ה-students והקורסים ל-לדאטה... איזה פונקציות לעשות?"

"מה זה ה-3 נקודות לפני?" – הסברנו על אופרטור הפריסה (... / Spread Operator) ואיך הוא משמש למיזוג ועדכון אובייקטים במערך.

2. בניית שכבת השירות (Service Layer)
הקשר בקוד: יצרנו קבצים בתיקיית services/ שבהם ממוקמת הלוגיקה העסקית, הבדיקות והחישובים (כמו חישוב ממוצע ציונים או בדיקת קיומם של משתמשים).

פרומפטים/שאלות שעלו:

"אוקי עכשיו אפשר לעבור לשלב בהא זה הסרוויס?"

"מה זה השורה הזאת import * as studentsData from ...? לפני זה היית מכניס תוך {} את כל השמות" – עמדנו על ההבדל בין ייבוא ספציפי של פונקציות לבין ייבוא של כל הקובץ כאובייקט אחד.

"תעשה לי את השירות גם של הרשמה לקורסים הישות החדשה." – הוספנו את enrollmentService.js עם בדיקות למניעת הרשמה כפולה.

3. בניית שכבת הבקרה (Controllers)
הקשר בקוד: יצרנו בקרים בתיקיית controllers/ שמקבלים בקשות HTTP (req), קוראים לשירותים ומחזירים תשובות (res) עם סטטוסי שגיאה/הצלחה מתאימים בתוך בלוקי try...catch.

פרומפטים שעלו:

"טוב עכשיו לשלב הבא" – בנינו את הבקרים עבור תלמידים, קורסים והרשמות (studentController, courseController, enrollmentController).

4. שכבת הנתוב (Routes) וחיבור השרת הראשי
הקשר בקוד: יצרנו ראוטרים בתיקיית routes/ שממפים את נתיבי ה-HTTP לפונקציות הבקר, וחיברנו אותם לקובץ השרת הראשי (app.js) דרך app.use().

פרומפטים שעלו:

"ועכשיו לשלב הבא" – הגדרנו את כל הראוטרים וסקרנו את המבנה המלא והמודולרי של הפרויקט.
